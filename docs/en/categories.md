# Seven format categories

PreviewDock keeps one product catalog for presets, documentation and the playground. All mode enables all seven categories; category mode installs only the presets a product exposes.

| Category | Families and formats |
| --- | --- |
| Office & Documents | DOC/DOCX/WPS, XLS/XLSX/XLSB/Numbers, PPT/PPTX/DPS, PDF/OFD/Typst, EML/MSG/MBOX, EPUB/UMD |
| Text & Data | text, Markdown, source code, JSON/YAML/TOML, notebooks, SQLite, Parquet, Avro, WASM and WebArchive |
| Archives | ZIP/ZIPX/JAR/WAR/APK, TAR/GZIP/BZ2/XZ/ZST, 7Z/RAR/CAB/ISO/XAR/LHA and comic archives |
| Images & Design | PNG/JPEG/WebP/AVIF, TIFF/TGA, HEIC/JXL, SVG/PSD/AI/EPS and web fonts |
| Media | MP3/WAV/OGG/FLAC, MP4/WebM/MOV, M3U8/HLS and MIDI |
| Diagrams & Engineering | BPMN/XMind/Visio, Draw.io/Excalidraw/Mermaid/PlantUML, GeoJSON/KML/GPX/SHP and EDA layouts |
| 3D & CAD | DXF/DWG/DWF, glTF/OBJ/STL/FBX/3MF, STEP/IGES/IFC/3DM, USD/USDZ and point/scientific models |

**Standard preview** provides a format-specific document, table, media or interactive model view. **Structural preview** displays real metadata, text, directories, layers, entities or byte structure without claiming desktop-editor fidelity.
