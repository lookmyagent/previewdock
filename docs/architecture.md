# 产品特点与使用边界

PreviewDock 为业务系统提供统一的浏览器文件预览体验，重点解决多格式接入不一致、文件外传风险和复杂能力影响页面性能的问题。

## 产品特点

### 一套组件

Office、PDF、文本、图片、压缩包、音视频、图表和模型使用同一个 Vue 组件。业务页面只负责提供文件和展示区域。

### 两种接入模式

- **All 模式**：一次接入七大类别，适合文件中心和通用预览；
- **分类模式**：只选择业务开放的类别，适合审批、知识库和垂直系统。

两种模式的页面用法完全相同，可以随着业务范围变化而调整。

### 本地优先

支持的文件默认在当前浏览器内处理。需要远程转换时，必须由宿主系统明确配置，并遵循自身的权限、审计和数据合规要求。

### 用到时启用

用户只查看常见文件时，不需要为专业文档、压缩包或工程模型承担额外的页面等待。大型能力还可以独立部署和缓存。

### 中英文一致

门户、文档和预览组件支持简体中文与英文，切换页面时保持当前语言和当前文档位置。

## 使用边界

- PreviewDock 是只读预览组件，不替代 Office、CAD 或专业设计软件；
- 不执行宏、脚本和其他活动内容；
- 复杂排版、字体、媒体编码和模型外部资源可能影响还原度；
- 宿主系统负责登录、权限、文件存储、下载授权、大小限制和审计；
- 旧版文档、部分压缩格式和工程模型可能需要额外运行资源。

上线前请结合[格式支持与兼容性](/format-support)和[运行环境与部署](/deployment)完成业务验证。
