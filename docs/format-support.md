# 格式支持与兼容性

“支持”表示可以在浏览器中呈现有用的只读内容，不代表与桌面专业软件像素级一致。正式上线前应使用业务真实文件验证。

| 类别 | 格式 | 当前状态 | 使用说明 |
| --- | --- | --- | --- |
| Office 与文档 | DOCX、XLSX、PPTX 及常见模板格式 | 可用 | 适合日常办公文档阅读；复杂字体、图表和特殊排版可能存在差异 |
| Office 与文档 | DOC、XLS、PPT、WPS、ET、DPS | 实验性 | 旧版 XLS 可直接预览；其他旧版格式可能需要额外转换能力 |
| Office 与文档 | PDF | 可用 | 使用浏览器支持的 PDF 阅读体验 |
| Office 与文档 | ODT、ODS、ODP、OFD、RTF、EPUB、EML | 实验性 | 提供结构化阅读，复杂样式需要真实文件验证 |
| 文本与数据 | TXT、Markdown、日志、常见源码 | 可用 | 提供文本或格式化阅读，不执行脚本 |
| 文本与数据 | CSV、TSV、JSON、XML | 可用 | 适合只读数据查看，大文件应设置业务限制 |
| 压缩包 | ZIP、JAR | 可用 | 普通模式支持 100 MB；大文件模式最高 1 GB，只读取目录并按选中文件解压 |
| 压缩包 | TAR、GZIP、TGZ | 可用 | 普通模式最高 100 MB；顺序压缩格式可能需要从头扫描 |
| 压缩包 | RAR、7Z | 实验性 | 普通模式最高 100 MB，需要额外运行资源；固实压缩可能需要处理完整数据块 |
| 图片 | PNG、JPEG、GIF、WebP、BMP、ICO、SVG | 可用 | 浏览器兼容性较好，SVG 活动内容不会执行 |
| 图片 | TIFF、TGA、PSD | 实验性 | 适合设计资产查看，不替代专业编辑软件 |
| 音视频 | MP3、WAV、OGG、AAC、FLAC、MP4、WebM、MOV | 可用 | 实际播放能力取决于文件编码和浏览器 |
| 图表与流程图 | BPMN、XMind、VSDX | 实验性 | 提供流程、思维导图或页面阅读视图 |
| 图表与流程图 | VSD、WMF、EMF | 实验性 | 可能需要额外转换能力 |
| 3D 与 CAD | GLB、glTF、OBJ、STL、PLY、FBX、3MF 等 | 实验性 | 提供旋转、缩放等交互；外部纹理可能需要一并提供 |
| 3D 与 CAD | DXF、STEP、IGES、BREP、3DM、IFC | 实验性 | 部分工程格式需要额外运行资源和更严格的文件限制 |
| 暂未开放 | DWG、FCSTD、BIM、SWF及部分旧媒体格式 | 未支持 | 不在当前上线承诺范围内 |

## 状态说明

- **可用**：已实现主要阅读能力，仍需根据业务文件验证兼容性；
- **实验性**：已有预览能力，但复杂文件、大文件和少见变体可能失败；
- **未支持**：当前版本不应向用户承诺。

PreviewDock 不执行宏、嵌入脚本或其他活动内容。文件大小、压缩包展开量、媒体编码和模型资源应由宿主系统设置明确边界。

远程 ZIP/JAR 使用大文件模式时，文件服务器必须支持 HTTP Range。服务端不支持分段读取时，超过 100 MB 的文件不会完整下载到浏览器，而是显示明确的环境提示。
