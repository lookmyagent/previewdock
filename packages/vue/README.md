# @previewdock/vue

PreviewDock 的 Vue 3 UI 组件，支持统一的文件加载、状态、错误、国际化和资源释放生命周期。

组件支持 `watermark` 字符串或配置对象，为所有预览格式统一添加可动态开关的展示水印。

```bash
pnpm add vue @previewdock/vue @previewdock/preset-all
```

同时引入 `@previewdock/vue/style.css`，并按照[快速开始](https://playground.yigeren.me/docs/getting-started)创建 Engine。
