# @previewdock/core

PreviewDock 的框架无关浏览器运行时，负责文件识别、适配器注册、加载生命周期、取消与资源释放。

通常请搭配 [`@previewdock/preset-all`](https://www.npmjs.com/package/@previewdock/preset-all) 或一个/多个 `@previewdock/preset-*` 使用。完整接入文档见 [PreviewDock Docs](https://playground.yigeren.me/docs/)。

```bash
pnpm add @previewdock/core @previewdock/preset-documents
```
