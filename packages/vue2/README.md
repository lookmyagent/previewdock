# @previewdock/vue2

PreviewDock 的 Vue 2.6.14 / Vue 2.7 Options API 接入层，与 Vue 3、React 和原生 Web 版本共享同一 Engine API。

支持与 Vue 3 一致的 `watermark` 字符串或配置对象。

```bash
pnpm add vue@2 @previewdock/vue2 @previewdock/preset-all
```

完整示例见[多框架接入文档](https://playground.yigeren.me/docs/frameworks)。
