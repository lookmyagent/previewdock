# Changelog

All notable changes to PreviewDock will be documented in this file.

The project follows semantic versioning after the first stable release. During
the Early Preview period, APIs, package names, and branding may still change.

## [Unreleased]

### Added

- Vue 2.6/2.7, React 16.8–19, native Web API, and Custom Element hosts.
- Seven-category format catalog shared by presets, portal, documentation,
  Playground, and regression tests.
- Self-hosted runtime asset package, copy CLI, Vite plugin, and unified
  `assetBaseUrl` configuration.
- Expanded archive, image, media, text/data, diagram, engineering, and 3D
  format routes with explicit standard or structural-preview fidelity.
- Separate product portal, documentation site, and full preview playground.
- Shared GitHub/Gitee project-link configuration.
- Documentation navigation, local search, quick start, API reference, and
  Worker/WASM deployment guidance.
- Repository, homepage, and issue metadata for publishable packages.

## [0.1.0] - Early Preview

- Initial adapter-based browser preview runtime prototype.
